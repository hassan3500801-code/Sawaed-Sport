# مشروع سواعد — نسخة تطوير أولية

## الملفات
- `index.html`: الواجهة الرئيسية وصفحة الحسابات والبطولات.
- `style.css`: تصميم الموقع.
- `script.js`: وظائف النسخة السابقة ونظام البطولات التجريبي.
- `backend.js`: واجهة التسجيل وطبقة Supabase وإدارة البطولات الجديدة.
- `supabase_schema.sql`: الجداول والصلاحيات ودوال التحقق من رقم الجلوس.
- `SUPABASE_SETUP_AR.md`: خطوات الربط خطوة بخطوة باللغة العربية.

## تشغيل سريع دون Supabase
افتح المجلد في VS Code وشغّل `index.html` عبر Live Server. وضع المالك القديم وبيانات البطولات المحلية للتجربة فقط، وهي غير مشتركة بين الأجهزة وغير مناسبة لبيانات حقيقية.

## ربط Supabase
اتبع `SUPABASE_SETUP_AR.md` بالترتيب. لا تضع مفتاح `service_role` أو كلمات مرور قاعدة البيانات داخل ملفات الواجهة.


## التحديث الأخير
أُزيل خيار وضع المالك ورمز المالك التجريبي من الواجهة. إدارة الفرق والبطولات والمباريات تعتمد على حساب مالك موثّق أو مشرف يعيّنه المالك من الإعدادات. صفحة «الفرق» مخصصة لبيانات الفرق والأندية واللاعبين، وصفحة «البطولات» لإدارة البطولات ومبارياتها. شغّل ملف SQL المحدّث في Supabase قبل اختبار هذه الوظائف.

## تحديث v3
- المباريات: صفحة «المباريات» و«آخر الأحداث» تعرضان فقط ما يضيفه المالك/المشرف، و«آخر الأحداث» تعرض أول مباراتين. شغّل الجزء الجديد الأخير من `supabase_schema.sql` (جدول `fixtures`).
- إصلاح صفحة «حسابي»: عناوين الاسم/رقم الجلوس كانت تظهر في وضع الدخول.
- شاشة ترحيب بالشعار الجديد (`logo.png`) واستبدال شعار الترويسة به.
- حركة انتقال خفيفة بين الصفحات.
- بطاقة «المباراة القادمة» وزر التفاصيل والعد التنازلي صارت تعرض أقرب مباراة قادمة يضيفها المالك/المشرف، وأُزيلت الإشعارات التجريبية الجاهزة.
- «ترتيب الدفعة» صار «ترتيب الفرق» لكل رياضة، يتحكم به المالك والمشرفون (إضافة/حذف فريق، النقاط، الترتيب). شغّل الجزء الجديد من `supabase_schema.sql` (جدول `team_standings`).
- «ترتيب الفرق» صار ترتيبًا إجماليًا واحدًا (تراكميًا) لكل الفرق بدل التقسيم حسب الرياضة. المالك والمشرفون يكتبون الأسماء والنقاط ويحركون الترتيب يدويًا بالأسهم، وتعديل النقاط لا يغيّر الترتيب تلقائيًا إلا بزر «ترتيب تلقائي». لا يلزم تغيير في SQL.

## تحديث v6
- الفرق: شعار لكل فريق (اختيار صورة من الجهاز وتصغيرها تلقائيًا)، وصفحة كاملة للفريق بلاعبيه وتفاصيله. التعديل والحذف بنماذج داخل التطبيق.
- البطولات: تُنشأ البطولة أولًا، ثم تُضاف إليها الفرق (من قائمة الفرق أو بالاسم)، ثم «بدء البطولة» لتوليد المباريات (دوري / مجموعات + إقصائيات / خروج المغلوب).
- الترتيب تلقائي حسب النقاط (ثم فارق الأهداف) في كل الجداول، وفي «ترتيب الفرق» بالرئيسية.
- استُبدلت نوافذ prompt/confirm/alert (تُحجب في كثير من متصفحات الجوال) بنوافذ داخل التطبيق.
- لقاعدة البيانات: شغّل آخر جزء في supabase_schema.sql (عمود logo لجدول team_catalog).

## تحديث v8
- حالة المباراة (لم تبدأ بعد / جارية / انتهت) بيد المالك والمشرفين، في المباريات العامة ومباريات البطولات.
- «تفاصيل المباراة»: تسجيل الأهداف والتمريرات الحاسمة (اللاعب والفريق والدقيقة) وتعديلها وحذفها، ونتيجة المباراة العامة.
- البطولات: قائمتا «الهدافون» و«صنّاع الأهداف» تُحسبان تلقائيًا من التسجيلات، ويمكن للمشرفين تصحيح اسم لاعب منها.
- بطاقة «المباراة القادمة» تعرض المباراة الجارية أولًا ثم أقرب مباراة لم تبدأ، مع تفاصيلها ومسجليها.
- شارة «حساب موثق» تظهر في صفحة «حسابي» للمالك والمشرفين فقط.
- استُبدلت كلمة «المدير» بـ«المالك» في التطبيق.
- مهم: شغّل `SAWAED_UPDATE.sql` في Supabase قبل الاستخدام.
