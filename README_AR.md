# مشروع سواعد — نسخة تطوير أولية

## الملفات
- `index.html`: الواجهة الرئيسية وصفحة الحسابات والبطولات.
- `style.css`: تصميم الموقع.
- `script.js`: وظائف النسخة السابقة ونظام البطولات التجريبي.
- `backend.js`: واجهة التسجيل وطبقة Supabase وإدارة البطولات الجديدة.
- `supabase_schema.sql`: الجداول والصلاحيات ودوال التحقق من رقم الجلوس.
- `SUPABASE_SETUP_AR.md`: خطوات الربط خطوة بخطوة باللغة العربية.

## تشغيل سريع دون Supabase
افتح المجلد في VS Code وشغّل `index.html` عبر Live Server. وضع المدير القديم وبيانات البطولات المحلية للتجربة فقط، وهي غير مشتركة بين الأجهزة وغير مناسبة لبيانات حقيقية.

## ربط Supabase
اتبع `SUPABASE_SETUP_AR.md` بالترتيب. لا تضع مفتاح `service_role` أو كلمات مرور قاعدة البيانات داخل ملفات الواجهة.


## التحديث الأخير
أُزيل خيار وضع المدير ورمز المدير التجريبي من الواجهة. إدارة الفرق والبطولات والمباريات تعتمد على حساب مدير موثّق أو مشرف يعيّنه المدير من الإعدادات. صفحة «الفرق» مخصصة لبيانات الفرق والأندية واللاعبين، وصفحة «البطولات» لإدارة البطولات ومبارياتها. شغّل ملف SQL المحدّث في Supabase قبل اختبار هذه الوظائف.

## تحديث v3
- المباريات: صفحة «المباريات» و«آخر الأحداث» تعرضان فقط ما يضيفه المدير/المشرف، و«آخر الأحداث» تعرض أول مباراتين. شغّل الجزء الجديد الأخير من `supabase_schema.sql` (جدول `fixtures`).
- إصلاح صفحة «حسابي»: عناوين الاسم/رقم الجلوس كانت تظهر في وضع الدخول.
- شاشة ترحيب بالشعار الجديد (`logo.png`) واستبدال شعار الترويسة به.
- حركة انتقال خفيفة بين الصفحات.
- بطاقة «المباراة القادمة» وزر التفاصيل والعد التنازلي صارت تعرض أقرب مباراة قادمة يضيفها المدير/المشرف، وأُزيلت الإشعارات التجريبية الجاهزة.
- «ترتيب الدفعة» صار «ترتيب الفرق» لكل رياضة، يتحكم به المدير والمشرفون (إضافة/حذف فريق، النقاط، الترتيب). شغّل الجزء الجديد من `supabase_schema.sql` (جدول `team_standings`).
- «ترتيب الفرق» صار ترتيبًا إجماليًا واحدًا (تراكميًا) لكل الفرق بدل التقسيم حسب الرياضة. المدير والمشرفون يكتبون الأسماء والنقاط ويحركون الترتيب يدويًا بالأسهم، وتعديل النقاط لا يغيّر الترتيب تلقائيًا إلا بزر «ترتيب تلقائي». لا يلزم تغيير في SQL.

## تحديث v6
- الفرق: شعار لكل فريق (اختيار صورة من الجهاز وتصغيرها تلقائيًا)، وصفحة كاملة للفريق بلاعبيه وتفاصيله. التعديل والحذف بنماذج داخل التطبيق.
- البطولات: تُنشأ البطولة أولًا، ثم تُضاف إليها الفرق (من قائمة الفرق أو بالاسم)، ثم «بدء البطولة» لتوليد المباريات (دوري / مجموعات + إقصائيات / خروج المغلوب).
- الترتيب تلقائي حسب النقاط (ثم فارق الأهداف) في كل الجداول، وفي «ترتيب الفرق» بالرئيسية.
- استُبدلت نوافذ prompt/confirm/alert (تُحجب في كثير من متصفحات الجوال) بنوافذ داخل التطبيق.
- لقاعدة البيانات: شغّل آخر جزء في supabase_schema.sql (عمود logo لجدول team_catalog).
