# تحديث سواعد — البطولات والمباريات والحسابات

## محتويات الحزمة
- `index.html`, `style.css`, `backend.js`: ملفات الواجهة والوظائف المعدلة.
- `script.js` و`config.js`: النسختان الأصليتان دون تعديل.
- `supabase_schema.sql`: مخطط قاعدة البيانات والتعديلات المطلوبة.
- `logo.png`, `favicon.png`: الصور الأصلية.

## طريقة التركيب
1. احتفظ بنسخة احتياطية من مجلد المشروع الحالي.
2. استبدل الملفات الموجودة بالملفات المرفقة، مع الإبقاء على `config.js` كما هو (النسخة المرفقة مطابقة للأصل).
3. افتح Supabase ثم SQL Editor وشغّل ملف `supabase_schema.sql` كاملًا.
4. تأكد أن جدول `approved_seat_numbers` يحتوي أرقام الجلوس الصحيحة قبل السماح بالتسجيل.
5. افتح التطبيق وسجّل الدخول بحساب مشرف، ثم اختبر التغييرات.

## ما الذي تغير؟
- صفحة البطولة تعرض هدافي البطولة وصنّاع الأهداف. يستطيع المدير والمشرف إضافة الحدث أو تعديله أو حذفه من بطاقة المباراة.
- صفحة المباريات تسمح للمشرف بتغيير الحالة: لم تبدأ بعد، جارية، انتهت.
- يستطيع المشرف تسجيل اسم مسجل الهدف والفريق والدقيقة في المباراة العامة.
- إنشاء الحساب يتطلب رقم جلوس موجودًا وغير مستخدم في `approved_seat_numbers`. بعد نجاح حجز الرقم يُنشأ الحساب بحالة `approved=true` تلقائيًا؛ لا توجد موافقة يدوية لاعتماد حساب الطالب.
- صلاحيات المدير والمشرفين (`admin` و`team_leader`) تبقى محمية بسياسات RLS في قاعدة البيانات.

## اختبار سريع
1. سجّل حساب طالب برقم جلوس موجود وغير مستخدم، وأكد البريد حسب إعداد Supabase.
2. تحقق أن `profiles.approved` أصبح `true` وأن الطالب يستطيع رؤية بيانات التطبيق.
3. بحساب مشرف، أضف بطولة وفريقين وابدأها، ثم أضف هدفًا وصناعة وتأكد من ظهور قوائم الهدافين والصناع.
4. أضف مباراة من صفحة المباريات، غيّر حالتها إلى جارية، وسجّل هدفًا؛ افتح التطبيق بحساب طالب وتحقق من ظهور الحالة والهدف.

## ملاحظة مهمة
تم فحص صياغة JavaScript باستخدام `node --check`. لم يتم تشغيل SQL على مشروع Supabase الخاص بك أو تجربة التطبيق على قاعدة بياناتك الفعلية؛ لذلك يجب تنفيذ الاختبارات أعلاه بعد التركيب.
